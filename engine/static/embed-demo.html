Deepcast Embed Widget

外部サイトにDeepcastのコンテンツを埋め込むための軽量ウィジェット。依存関係なし、コピペで導入可能。

Light Theme（デフォルト）

最小構成。scriptタグを1行追加するだけでウィジェットが表示されます。

<!-- コピペ用コード -->
<div id="deepcast-widget"></div>
<script src="http://localhost:8000/api/embed/latest.js"
        data-api-url="http://localhost:8000"
        data-language="ja"
        data-count="3"
        data-theme="light"></script>

Dark Theme

data-theme="dark" を指定するとダークモードになります。

<div id="deepcast-dark"></div>
<script src="http://localhost:8000/api/embed/latest.js"
        data-api-url="http://localhost:8000"
        data-language="ja"
        data-count="3"
        data-theme="dark"
        data-container="deepcast-dark"></script>

English / 5 items

data-language="en" と data-count="5" で英語コンテンツを5件表示。

<script src="http://localhost:8000/api/embed/latest.js"
        data-api-url="http://localhost:8000"
        data-language="en"
        data-count="5"
        data-theme="light"
        data-container="deepcast-en"></script>

設定オプション一覧

属性 デフォルト 説明
data-api-url "" (same origin) APIサーバーのベースURL
data-language "ja" 表示言語（ja / en）
data-count 3 表示件数
data-theme "light" テーマ（light / dark）
data-container "deepcast-widget" ウィジェットを挿入するコンテナのID
