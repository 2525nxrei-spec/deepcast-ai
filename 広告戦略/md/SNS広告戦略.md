前提：収益モデルの段階設計
DeepCastは初期フェーズではAdSense収益をメインの収益源とする。有料課金（Pro/Businessプラン）はリ
スナー基盤が十分に育ってからの導入となるため、本戦略では「いかに低コストでリスナー数（=PV・再生数）
を最大化し、AdSense収益を早期に安定させるか」を最優先の設計思想とする。
収益ステージの全体像:
1. Stage 1（0〜12ヶ月）: AdSense収益のみ。広告費は「リスナー基盤構築への先行投資」
2. Stage 2（12ヶ月〜）: AdSense + 有料課金プラン導入。損益分岐点を目指す
3. Stage 3（18ヶ月〜）: AdSense + 課金 + スポンサーシップ。黒字化・収益拡大
1. プラットフォーム選定
1.1 優先度A：X（Twitter）— 最重要チャネル
選定根拠（市場調査データに基づく）:
• メインターゲット（ペルソナA:
25〜39歳ビジネスパーソン）の情報収集プラットフォームとして市場調査で明確に特定（X, はてブ,
NewsPicks, Spotify）
• テック・ビジネス系の話題が自然に拡散されるエコシステムが存在し、バズれば広告費以上のオーガニックリ
ーチを獲得できる
• テキスト＋音声プレビュー（短尺動画）の組み合わせ広告が可能
• CPCが比較的安価（日本市場で30〜80円程度）で、限られた予算での検証に最適
• ペルソナA（ビジネスパーソン）・ペルソナB（テック好き学生）の両方がアクティブユーザー
• ポッドキャストリスナーの決裁権者比率13.1%という調査結果と、X上のビジネス層の親和性が高い
活用方針: 認知獲得＋サイト流入（=AdSense
PV増加）のメインチャネル。広告とオーガニック投稿の両輪で運用。
1.2 優先度A：Instagram（リール中心）
選定根拠:
• 15〜30秒のリール動画で「エピソードのハイライト音声」を直接体験させられる。AI音声品質の訴求に最適
• 20代〜30代前半の利用率が高く、ペルソナA・Bをカバー
• 音声コンテンツの視覚的訴求（波形アニメーション＋字幕）との相性が良い
• リール広告のリーチ単価が低い（CPM 200〜500円）ため、少額予算でも広いリーチを確保可能
• 市場調査で判明した「ながら聴き実施率80.8%」を訴求するビジュアル広告に最適
活用方針: ブランド認知と「5分で学べる」世界観の醸成。リール広告を中心にサイト流入を促進。
1.3 優先度B：YouTube Shorts / TikTok
選定根拠:
• ペルソナB（18〜24歳テック好き学生）の主要プラットフォーム（市場調査: YouTube, TikTok,
Instagram, X）
• 15〜19歳のポッドキャスト利用率が40.5%と急伸（前年比+6.5pt）しており、将来のリスナー基盤を早期
に囲い込む価値がある
• ショート動画でエピソードの冒頭30秒を流し、「続きはDeepCastで」の導線でサイトPVに転換可能
• オーガニック投稿でもリーチが取りやすく、広告費をかけずとも一定の効果が期待できる
活用方針: サブターゲット若年層の獲得。広告予算は限定的にし、オーガニック投稿を軸にする。Phase
2以降で本格的に広告予算を配分。
1.4 優先度C：LinkedIn
選定根拠:
• ペルソナC（35〜50歳の経営者・意思決定者）へのリーチに最適
• 市場調査でポッドキャストリスナーの13.1%が企業の決裁権者と判明しており、高単価ターゲットへのアプ
ローチに有効
• ただしCPCが高い（300〜800円）ため、AdSense収益メインの初期フェーズでは費用対効果が合わない
活用方針: 初期はオーガニック投稿のみ。有料課金プラン（Business ¥1,980/月）導入後に広告出稿を開始。

4.4 AdSense収益との損益分岐点分析
前提条件
• AdSense RPM（1,000PVあたり収益）: 日本語テック系コンテンツで ¥5〜15（保守的に¥8で試算）
• 広告経由の訪問者1人あたり平均PV: 3PV（エピソード聴取ページ + 関連ページ回遊）
• 広告CPC: Phase安定後 ¥50
直接収益の計算
1クリックあたりのAdSense直接収益:
  = RPM × 平均PV / 1,000
  = ¥8 × 3 / 1,000
  = ¥0.024
→ CPC ¥50に対してAdSense直接収益は¥0.024
→ 広告クリック単体ではAdSense収益で広告費を回収できない
これは想定通りであり、問題ではない。 SNS広告の目的は「クリック単体のAdSense収益回収」ではなく、リ
スナー基盤の構築によるオーガニックトラフィックの持続的拡大にある。
リスナー1人あたりの生涯価値（AdSense LTV）
リスナー1人のAdSense LTV:
  = 月間訪問回数 × 平均PV × RPM/1,000 × 継続月数
  = 15回/月 × 3PV × ¥8/1,000 × 12ヶ月
  = ¥4.32
リスナー1人の獲得コスト（CAC）:
  = CPC / CVR
  = ¥50 / 0.25
  = ¥200
単純なAdSense LTVではCACを回収できない。
これが「AdSenseだけでは広告費を回収できないが、リスナー基盤への先行投資として合理的」という方針の根
拠である。

必要月間PV = 広告費 / (RPM / 1,000)
Phase 3の場合: ¥150,000 / (¥8 / 1,000) = 18,750,000 PV
AdSense収益のみでの広告費全額回収は現実的ではない。
これが「リスナー基盤が育ったら有料課金を導入する」という段階的収益モデルの合理性を裏付けている。
結論
SNS広告は「AdSense収益で直接回収する手段」ではなく、「将来の課金収益・スポンサー収益を生むリスナー
基盤への先行投資」として位置づける。ただし、広告投下によるPV増加はAdSense収益を底上げし、赤字幅の
圧縮に確実に寄与する。12ヶ月間の累計投資額は約100万円を想定し、課金プラン導入後6ヶ月以内の投資回収
を目標とする。
